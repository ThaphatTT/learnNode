# Node.js Backend Review Project

This project is created as a **personal practice and review** for Node.js backend development.

## 🎯 Purpose

The main goal of this project is to:

- Practice setting up a Node.js backend server with Express.js
- Explore folder structures for scalable backend applications
- Learn and review how to:
  - Implement routes, controllers, services, and repositories
  - Connect to a database securely
  - Use environment variables for configuration
  - Apply basic security best practices

## 🚀 Tech Stack

- Node.js
- Express.js
- MongoDB (with Mongoose)
- dotenv
